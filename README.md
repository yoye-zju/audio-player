# 🎧 音频字幕播放器 Audio Subtitle Player

一个零依赖、单文件的本地音频播放器，主打**音频 + 字幕逐句对照**。支持直接在浏览器里播放本地录音、逐句高亮字幕、点击跳转、在线编辑字幕文本。无需安装、无需联网、数据只留在本机。

- 纯原生 HTML / CSS / JavaScript，**单文件** `index.html`，无任何前端依赖
- 可选的 Python 伴生服务（仅标准库），用于浏览磁盘目录、把播放列表存成文件、一键打开所在目录
- 离线双击 `index.html` 也能用（播放列表存浏览器 IndexedDB）

## 功能特性

- **字幕逐句高亮**：播放到哪句高亮哪句，点击任意句子跳转到对应时间
- **四种字幕格式**：
  - `SRT` / `VTT` / `LRC`
  - 会议转写文本（`讲话人 1 00:00` + 正文，兼容「讲话人 / 说话人 / Speaker」，Word 另存的 GBK txt 也能自动识别编码）
- **进度条自由拖动**（支持音频 Range 请求，不整段重下）
- **分级快进快退**：`←/→` ±5 秒、`Shift` ±10 秒、`Ctrl` ±20 秒、`Alt` ±30 秒；控制栏另有 ±30/20/10/5 按钮
- **倍速**：0.5x – 2x，快捷键 `[` `]`
- **播放列表**：自动记录音频、字幕与播放进度，下次点开即续播
- **字幕在线编辑**：时间轴锁定只改文本，按原文件编码保真回写、首次保存自动生成 `.bak` 备份，也可另存导出
- 拖拽载入音频与字幕，全套键盘快捷键

## 快速开始

### 方式一：本地服务模式（推荐，功能完整）

需要 [Python 3](https://www.python.org/)（仅用标准库）。

- Windows：双击 **`启动播放器.bat`**
- 或命令行：

```bash
python server.py
```

启动后自动打开浏览器访问 <http://localhost:8765>，并在系统托盘对应窗口运行服务。
此模式下「选择音频」会打开**目录浏览框**直接读取磁盘文件，播放列表以原始路径形式保存在程序同目录的 `playlist.json`（不会复制你的音频文件）。

可用环境变量：`PLAYER_PORT`（默认 8765）、`PLAYER_HEADLESS=1`（不自动开浏览器）。

### 方式二：纯离线模式

直接双击用浏览器打开 **`index.html`** 即可。
此模式播放列表保存在浏览器本地（IndexedDB）；受浏览器安全限制，文件需通过拖拽或「选择文件」载入。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `Shift + ←/→` | 10 秒 |
| `Ctrl + ←/→` | 20 秒 |
| `Alt + ←/→` | 30 秒 |
| `↑` / `↓` | 音量加 / 减 |
| `[` / `]` | 减速 / 加速 |
| `M` | 静音 |
| `Esc` | 关闭弹窗 / 退出字幕编辑焦点 |
| `Ctrl + S` | 字幕编辑中保存 |

## 字幕编辑说明

- 进入字幕后点击「✏️ 编辑」，**时间轴不可修改，只能改正文**
- 保存时按原文件编码（UTF-8 / UTF-8 BOM / UTF-16 / GB18030）写回，尽量保持原有排版
- 第一次保存会在字幕旁生成 `文件名.bak` 备份（已存在则不覆盖）
- 无实际改动不会写盘

## 目录结构

```
.
├── index.html          # 播放器本体（单文件，含全部前端逻辑）
├── server.py           # 可选：本地伴生服务（Python 标准库，零依赖）
├── 启动播放器.bat       # Windows 一键启动
├── examples/           # 合成的示例字幕（SRT / 会议转写）
└── README.md
```

运行后自动生成、且**不会**纳入版本库的本地数据：`playlist.json`、`媒体库/`。

## 隐私

- 程序完全在本机运行，不上传任何音频、字幕或播放记录
- 本地服务只监听 `127.0.0.1`，不对局域网开放
- `playlist.json` 仅保存你本机的文件路径与播放进度
